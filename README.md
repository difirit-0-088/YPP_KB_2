# УПП_КБ_2

## Project Goal

Разработка сайта проката техники (ноутбуки, компьютеры) с онлайн-бронированием и учётом выдачи/браков/просрочек.

## Инструкция по запуску

1. Открыть терминал и склонировать репозиторий: git clone https://github.com/difirit-0-088/YPP_KB_2.git
2. Перейти в папку проекта: cd YPP_KB_2
3. Настроить базу данных (SQL): 
   - Разверните базу данных, выполнив скрипт из файла `database.sql` (или `schema.sql`) в вашей СУБД (например, SQL Server или PostgreSQL).
   - Проверьте строку подключения (Connection String) в файле `appsettings.json` в папке с C#-кодом, чтобы она указывала на вашу локальную базу.
4. Запустить бэкенд (C#): dotnet run
   (или откройте файл решения .sln в Visual Studio и нажмите F5)
5. Открыть в браузере: http://localhost:5000 (или тот порт, который выдаст консоль при запуске)
