# УПП_КБ_2

## Project Goal

Разработка сайта проката техники (ноутбуки, компьютеры) с онлайн-бронированием и учётом выдачи/браков/просрочек.

## Инструкция по запуску

1. Открыть терминал и склонировать репозиторий: git clone https://github.com/difirit-0-088/YPP_KB_2.git
2. Перейти в папку проекта: cd YPP_KB_2
3. Настроить базу данных (SQL): 
   - Разверните базу данных, выполнив скрипт из файла `database.sql` в нашей СУБД (SSMS).
   - Проверьте строку подключения в файле `appsettings.json` в папке с C#-кодом, чтобы она указывала на нашу локальную базу.
4. Запустить бэкенд (C#)
5. Открыть в браузере: http://localhost:5000
